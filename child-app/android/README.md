# Child app — Android native (Phase 2)

Native monitoring code lives under `app/src/main/java/com/childmonitor/`.

## Components

| Class | Purpose |
|-------|---------|
| `NotificationCaptureService` | `NotificationListenerService` — captures notifications to local store |
| `NotificationStore` | SharedPreferences queue for pending notifications |
| `UsageStatsReader` | Reads `UsageStatsManager` aggregates |
| `LocationReader` | Last-known GPS/network location |
| `NativeSyncUploader` | HTTP POST to backend (runs in foreground service) |
| `MonitoringForegroundService` | Persistent notification + 5 min sync loop |
| `BootReceiver` | Restarts service after `BOOT_COMPLETED` when paired |
| `ChildMonitorNativeModule` | React Native bridge |

## Integration with React Native project

If `android/` was generated by React Native CLI:

1. Copy all Kotlin sources from `app/src/main/java/com/childmonitor/` into your project.
2. Merge `AndroidManifest.xml` entries (permissions, services, receiver) into `android/app/src/main/AndroidManifest.xml`.
3. Register `ChildMonitorNativePackage` in `MainApplication.kt`:

```kotlin
override fun getPackages(): List<ReactPackage> =
    PackageList(this).packages.apply {
        add(ChildMonitorNativePackage())
    }
```

4. Rebuild: `cd child-app && npm run android`.

## Permissions (user must grant manually)

- **Notification access** — Settings → Notification access → enable app
- **Usage access** — Settings → Special access → Usage access
- **Location** — runtime prompt from app
